# 精读二：Flow 事件驱动编排

源码：`lib/crewai/src/crewai/flow/`，重点 `flow.py`、`runtime/`、`persistence/`、`dsl/`、`human_feedback.py`、`conversational.py`。

## 任务

1. **入口与状态**：复现 `Flow` 的节点注册、状态对象和同步调用；对照组是一个把状态散落在全局变量里的脚本。
2. **条件转移**：实现成功、失败和条件分支，打印节点进入/离开顺序；对照组是嵌套 `if`，说明声明式转移带来的可视化和测试收益。
3. **持久化与人在环**：用内存 checkpoint 实现暂停、恢复和人工反馈；标注这是教学简化，并解释生产存储需要解决的幂等与并发。
4. **Agent 嵌入 Flow**：节点内部调用真实 LLM 驱动的 Agent/Crew，证明 Flow 控制外层拓扑、Agent 只负责节点内推理。

## 验收

必须展示一条成功路径、一条失败后恢复路径，以及“节点由代码决定、节点内答案由模型决定”的边界。报告要说明 Flow 不是“完全不用 LLM”。
